# Grandpa vs. the Smart Speaker (Laughing Box, episode 5)

An original 60.6 s cartoon in **4K** 9:16 with English voices. Grandpa takes on a tiny smart speaker that mishears everything. It reuses the series' characters, the living room, Mittens, and the shared voice engine, sound effects and theme music. New: the smart speaker (it uses the series' machine voice), the delivery box and feathers, disco lights, and the 3 a.m. scene.

"Baby Duck Disco" is an invented song: the series theme played as a disco groove. No real song is named or played.

- **Video:** [`grandpa-vs-smart-speaker-4k.mp4`](grandpa-vs-smart-speaker-4k.mp4), **2160×3840 (4K UHD, 9:16)**, 24 fps, H.264 + AAC 48 kHz, −14 LUFS
- **Cover (9:16):** [`cover-1080x1920.png`](cover-1080x1920.png)
- **Contact sheet (1 frame / 2 s):** [`contact-sheet.jpg`](contact-sheet.jpg)

All characters, sets, art, voices and sound are generated by the scripts in this folder and the earlier episodes'. No third-party artwork, samples or music are used.

## Rebuild

Needs the same setup as [episode 1](../01-grandpa-vs-self-checkout/README.md#rebuild) (pycairo, numpy, scipy, ffmpeg, kokoro-onnx, soundfile, librosa and the Kokoro model files).

```bash
python make_video.py --stills stills/                               # optional: one 1080p PNG per shot
python make_voice.py MODEL_DIR voice_track.wav voice_track.json     # reports any line that overlaps the next
VOICE_WAV=voice_track.wav python make_audio.py soundtrack.wav
python make_video.py picture.mp4                                    # 4K, ~7 min on 4 cores; SCALE=1 for a 1080p preview
ffmpeg -i picture.mp4 -i soundtrack.wav -filter:a "loudnorm=I=-14:TP=-2.5:LRA=11,alimiter=limit=0.84:level=false" \
  -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest -movflags +faststart grandpa-vs-smart-speaker-4k.mp4
python make_thumbnail.py .                                          # cover-1080x1920.png
```

Shots, SFX cues and the script are in `timeline.py`. `ep1.py` loads the earlier episodes' modules so all episodes share one character library.
