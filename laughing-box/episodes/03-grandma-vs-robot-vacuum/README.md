# Grandma vs. the Robot Vacuum (Laughing Box, episode 3)

An original 58 s cartoon in **4K** 9:16 with English voices. Grandma gets her own episode. It reuses the series' characters, Leo and the living room from episode 2, and the same voice engine, sound effects and theme music.

- **Video:** [`grandma-vs-robot-vacuum-4k.mp4`](grandma-vs-robot-vacuum-4k.mp4), **2160×3840 (4K UHD, 9:16)**, 24 fps, H.264 + AAC 48 kHz, −14 LUFS
- **Cover (9:16):** [`cover-1080x1920.png`](cover-1080x1920.png)
- **Contact sheet (1 frame / 2 s):** [`contact-sheet.jpg`](contact-sheet.jpg)

All characters, sets, art, voices and sound are generated by the scripts in this folder and the earlier episodes'. No third-party artwork, samples or music are used.

## 4K

`make_video.py` draws on a 1080×1920 canvas and scales it by `SCALE` (default `2`, so 2160×3840). All drawing is vector, so every line and caption is rendered natively at 4K, not upscaled. Upload the 4K file everywhere. YouTube gives 4K uploads a higher-quality encode, even for viewers watching at 1080p. Facebook and Instagram downscale it automatically.

## Rebuild

Needs the same setup as [episode 1](../01-grandpa-vs-self-checkout/README.md#rebuild) (pycairo, numpy, scipy, ffmpeg, kokoro-onnx, soundfile, librosa and the Kokoro model files).

```bash
python make_video.py --stills stills/                               # optional: one 1080p PNG per shot
python make_voice.py MODEL_DIR voice_track.wav voice_track.json     # reports any line that overlaps the next
VOICE_WAV=voice_track.wav python make_audio.py soundtrack.wav
python make_video.py picture.mp4                                    # 4K, ~6 min on 4 cores; SCALE=1 for a 1080p preview
ffmpeg -i picture.mp4 -i soundtrack.wav -filter:a "loudnorm=I=-14:TP=-1.5:LRA=11" \
  -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest -movflags +faststart grandma-vs-robot-vacuum-4k.mp4
python make_thumbnail.py .                                          # cover-1080x1920.png
```

Shots, SFX cues and the script are in `timeline.py`. `ep1.py` loads the earlier episodes' modules so all episodes share one character library.
