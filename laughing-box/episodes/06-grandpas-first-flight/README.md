# Grandpa's First Flight (Laughing Box, episode 6)

An original 58 s cartoon in **4K** 9:16 with English voices. It's the family's first episode away from home: Grandpa flies for the first time. It reuses the series' characters and the shared voice engine, sound effects and theme music. New: the airplane cabin, seats, call-button panel, life vest, window views (runway, clouds, sunset), the plane exterior with a Laughing Box tail, **Rosa** the flight attendant, and the pilot's voice over the cabin speaker.

- **Video:** [`grandpas-first-flight-4k.mp4`](grandpas-first-flight-4k.mp4), **2160×3840 (4K UHD, 9:16)**, 24 fps, H.264 + AAC 48 kHz, −14 LUFS
- **Cover (9:16):** [`cover-1080x1920.png`](cover-1080x1920.png)
- **Contact sheet (1 frame / 2 s):** [`contact-sheet.jpg`](contact-sheet.jpg)

All characters, sets, art, voices and sound are generated by the scripts in this folder and the earlier episodes'. No third-party artwork, samples or music are used.

## Story beats

| Time | Beat |
|---|---|
| 0–5.0 s | **Hook:** a finger hammers the call button: DING ×4, "x 40". Rosa: "Yes, sir... again?" |
| 5.0–10.6 s | **Setup:** Grandpa, Grandma and Leo in a row. "Metal can't fly. It's science!" / "Relax, Grandpa. It's safe!" |
| 10.6–16.0 s | **Escalation A:** "This belt is too short!" His arm stretches and buckles Grandma's belt. "Harold. That's MY belt." |
| 16.0–23.4 s | **Escalation B:** "Never pull this tab inside the plane." / "This tab?" POOF! He's a giant orange balloon |
| 23.4–31.6 s | **Escalation C:** takeoff with the runway rushing past, "Whoooaaa!", then the plane above the clouds |
| 31.6–39.4 s | **The call button:** x38 "Water, please!", x39 "Are we falling?", x40 "Is that cloud normal?" Rosa twitches: "That's forty times, sir." |
| 39.4–45.6 s | **Twist 1:** Grandma sleeps in an eye mask. Sunset through the window: "Flying is... wonderful!" |
| 45.6–54.0 s | **Twist 2:** "We have landed. Welcome home!" / "No! One more time!" He's stuck in the seat in his balloon vest. Rosa and Leo pull, and POP! he shoots down the aisle |
| 54.0–58.0 s | **Button/loop:** DING. "Yes, sir?" / "When is the next flight?" Back to the call button from the hook |

## Rebuild

Needs the same setup as [episode 1](../01-grandpa-vs-self-checkout/README.md#rebuild) (pycairo, numpy, scipy, ffmpeg, kokoro-onnx, soundfile, librosa and the Kokoro model files).

```bash
python make_video.py --stills stills/                               # optional: one 1080p PNG per shot
python make_voice.py MODEL_DIR voice_track.wav voice_track.json     # reports any line that overlaps the next
VOICE_WAV=voice_track.wav python make_audio.py soundtrack.wav
python make_video.py picture.mp4                                    # 4K, ~7 min on 4 cores; SCALE=1 for a 1080p preview
ffmpeg -i picture.mp4 -i soundtrack.wav -filter:a "loudnorm=I=-14:TP=-2.5:LRA=11,alimiter=limit=0.84:level=false" \
  -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest -movflags +faststart grandpas-first-flight-4k.mp4
python make_thumbnail.py .                                          # cover-1080x1920.png
```

Shots, SFX cues and the script are in `timeline.py`. `ep1.py` loads the earlier episodes' modules so all episodes share one character library.
