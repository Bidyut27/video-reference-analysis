# Grandpa vs. the Video Call (Laughing Box, episode 2)

An original 57.7 s cartoon in 9:16 with English voices. It continues the "Grandpa vs." series and reuses episode 1's characters, voice engine, sound effects and theme music, so the series looks and sounds the same.

- **Video:** [`grandpa-vs-video-call.mp4`](grandpa-vs-video-call.mp4), 1080×1920, 24 fps, H.264 + AAC 48 kHz, −14 LUFS
- **Cover (9:16):** [`cover-1080x1920.png`](cover-1080x1920.png)
- **Contact sheet (1 frame / 2 s):** [`contact-sheet.jpg`](contact-sheet.jpg)

All characters, sets, art, voices and sound are generated by the scripts in this folder and episode 1's. No third-party artwork, samples or music are used.

## Story beats

| Time | Beat |
|---|---|
| 0–2.8 s | **Hook:** the screen is filled by a giant nose. Leo: "Grandpa... is that your nose?" |
| 2.8–9.6 s | **Setup:** Grandpa naps, the phone rings, he answers with one big finger |
| 9.6–15.0 s | **Escalation A:** phone held against his nose; Leo sees only nostrils |
| 15.0–21.2 s | **Escalation B:** phone held above his head; Leo sees only his shiny forehead |
| 21.2–31.1 s | **Escalation C:** he pokes the screen, turns on a cat filter, tries to wipe it off |
| 31.1–36.5 s | **Breather gag:** he holds the phone to his ear and shouts; Leo facepalms |
| 36.5–43.7 s | **Twist 1:** Grandma takes the phone and fixes it with one tap |
| 43.7–52.3 s | **Twist 2:** Grandma's smug extra tap turns the cat filter on her |
| 52.3–57.7 s | **Button/loop:** "Bye, Leo!" and he leans in, back to the nose from the hook |

## Rebuild

Needs the same setup as [episode 1](../01-grandpa-vs-self-checkout/README.md#rebuild) (pycairo, numpy, scipy, ffmpeg, kokoro-onnx, soundfile, librosa and the Kokoro model files).

```bash
python make_video.py --stills stills/                               # optional: one PNG per shot
python make_voice.py MODEL_DIR voice_track.wav voice_track.json     # reports any line that overlaps the next
VOICE_WAV=voice_track.wav python make_audio.py soundtrack.wav
python make_video.py picture.mp4
ffmpeg -i picture.mp4 -i soundtrack.wav -filter:a "loudnorm=I=-14:TP=-1.5:LRA=11" \
  -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest -movflags +faststart grandpa-vs-video-call.mp4
python make_thumbnail.py .                                          # cover-1080x1920.png
```

Shots, SFX cues and the script are in `timeline.py`. `ep1.py` loads episode 1's modules so both episodes share one character library.
