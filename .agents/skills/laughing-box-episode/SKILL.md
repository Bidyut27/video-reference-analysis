# Laughing Box episode

Laughing Box is an original cartoon comedy channel for a worldwide, all-ages audience (YouTube Shorts, Facebook Reels, Instagram Reels). Every episode is a 55–75 s vertical cartoon with simple English voices, burned-in captions and a 9:16 cover. Everything is generated by code in this repo: no third-party art, music, samples or fonts.

Read these before starting:

- [`references/series-bible.md`](references/series-bible.md): characters, voices, colours, sets, episode log. **Stay on-model.**
- [`../../../laughing-box/production/blueprint.md`](../../../laughing-box/production/blueprint.md): story structure, safe zones and audio rules.
- [`../../../laughing-box/production/templates.md`](../../../laughing-box/production/templates.md): QC checklist (section 5).
- The newest episode folder under `laughing-box/episodes/` is the template to copy (currently `laughing-box/episodes/06-grandpas-first-flight/`). Name new folders `NN-<slug>` with the next number (e.g. `07-beach-day-seagull-heist`).

No code execution (a chat-only AI)? Use [`references/chat-prompt.md`](references/chat-prompt.md) instead.

## Deliverables (every episode)

| File | Spec |
|---|---|
| `laughing-box/episodes/<NN-slug>/<slug>-4k.mp4` | 2160×3840, 24 fps, H.264 High + AAC 48 kHz, −14 LUFS integrated, peak ≤ −1 dBFS, 55–75 s |
| `laughing-box/episodes/<NN-slug>/cover-1080x1920.png` | 9:16 cover only (no 16:9 thumbnail) |
| `laughing-box/episodes/<NN-slug>/contact-sheet.jpg` | 1 frame / 2 s review sheet |
| `laughing-box/episodes/<NN-slug>/README.md` | Story beats table, posting copy for all 3 platforms, rebuild commands |
| Scripts | `timeline.py`, `make_video.py`, `make_voice.py`, `make_audio.py`, `make_thumbnail.py`, `ep1.py` (+ `voice_track.wav/.json`) |

## Workflow

### 1. Pick the topic

If the user hasn't chosen one, offer 1 top pick plus 4–5 options in a table. Rules:

- Alternate between a **"Grandpa vs."** (or "Grandma vs.") tech episode and a **new character** or other family member, so the channel isn't one joke.
- The idea must be universal (no local slang, no country-specific jokes) and readable with the sound off.
- Check the episode log in the series bible so you don't repeat a premise.

Wait for the user to say "go" before building.

### 2. Write the story (`timeline.py`)

Use the structure **Hook → Setup → 3 Escalations → New challenger → Twist 1 → Twist 2 → Button that loops to the hook**:

- 0–3 s hook: an absurd image or action, no establishing shot.
- Something changes on screen at least every 2 s; a new question every 10–15 s.
- A second character must arrive before ~35 s.
- The last shot visually rhymes with the first so the Short loops.
- `SHOTS = [(name, seconds, [(local_t, "sfx"), ...]), ...]`, 18–24 shots.
- `LINES = [(shot, local_t, speaker, "line"), ...]`: short, simple English (≤ 8 words where possible), 15–20 lines.
- Keep the `shots()/starts()/total()` helpers so the shared voice/audio code works.

### 3. Picture (`make_video.py`)

- Copy the newest episode folder and replace the shots. Import characters and helpers from episode 1 (`ep1.video()`) and sets/props from earlier episodes (`ep1.ep2_video()` for the living room, armchair, Leo, phone). **Never redraw an existing character.** Add new characters as dicts in the same style (see the bible).
- Draw on a 1080×1920 canvas; `SCALE=2` (default) renders native 4K.
- Faces and text inside the safe zone: avoid the top ~220 px and bottom ~380 px, and keep ~120 px clear on the right.
- `python make_video.py --stills /tmp/stills` and tile them into a contact sheet. **Look at every still** before the full render: on-model faces, readable action, nothing cut off, props the right size (they read small in wide shots; scale up).
- Export a module-level `SHOT_FUNCS` and assert it matches `SHOTS` inside `main()`, not at import, so later episodes can import this one.

### 4. Voices (`make_voice.py`)

`python make_voice.py MODEL_DIR voice_track.wav voice_track.json` with the Kokoro model files (`kokoro-v1.0.onnx`, `voices-v1.0.bin`). Use the voice table in the bible; add new speakers to `v.VOICES`. The script must print **ALL LINES FIT**. If a line overlaps, lengthen the shot or shorten the line.

### 5. Sound (`make_audio.py`)

Reuse the series SFX (`ep1.audio().SFX`, `ep1.ep2_audio().SFX`) and theme music (`A.music`, `A.pad`). Music plan: quiet pad in the setup → score enters on the first escalation → **silence drop** on the biggest gag → light marimba for the twist → full score into the loop. Dialogue ducks music by 60 % and SFX by 35 %.

### 6. Render and mux

```bash
VOICE_WAV=voice_track.wav python make_audio.py /tmp/soundtrack.wav
python make_video.py /tmp/picture.mp4            # 4K; run in the background (~6 min on 4 cores)
ffmpeg -i /tmp/picture.mp4 -i /tmp/soundtrack.wav -filter:a "loudnorm=I=-14:TP=-2.5:LRA=11,alimiter=limit=0.84:level=false" \
  -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest -movflags +faststart <slug>-4k.mp4
ffmpeg -i <slug>-4k.mp4 -vf "fps=1/2,scale=216:384,tile=6x5:padding=4" -frames:v 1 contact-sheet.jpg
```

Verify with ffprobe (2160×3840, frame count = duration × 24) and `ebur128` (I ≈ −14 LUFS, peak ≤ −1 dBFS). Review the contact sheet and one full-resolution crop.

### 7. Cover (`make_thumbnail.py`)

9:16, 1080×1920, built with `ep1.thumb()` helpers (`background`, `big_text`):

- Headline of 2–4 words in the series style: `GRANDPA` / `VS THE` (red) / `<THING>` (white).
- The main character's face large, with a strong expression; the conflict readable without the text.
- Title and faces inside the centre 3:4 area (y 240–1680) that Instagram's profile grid shows. Check with a drawn box before shipping.

### 8. Posting copy (in the episode README)

- **YouTube Shorts:** title `<Title> <2 emoji> #shorts`, a 2-line hook description, "Welcome to Laughing Box: original cartoon comedy for everyone 🌍📦", subscribe line, 6–7 hashtags starting `#LaughingBox #CartoonComedy`. Audience: **not made for kids**. Category: Comedy. Add a playlist if it's a series.
- **Facebook Reel:** title, one-line hook, "📦 New Laughing Box episode!", a comment question ("Tag someone who…"), 5–6 hashtags.
- **Instagram Reel:** like Facebook, plus `#Reels #Comedy #FunnyVideos`.
- Never use "kids", "children" or "nursery" in titles, tags or keywords. It risks a "Made for Kids" classification (no comments, lower reach).

### 9. Finish

- Remove `__pycache__`, commit the episode folder, and push.
- Show the user the video (a 1080p preview is fine in chat; the 4K file lives in the repo), the cover, and the YouTube title. Report the measured duration, resolution, loudness, "ALL LINES FIT", and anything not verified (e.g. not watched on a phone with sound).
- Add the episode to the log in `references/series-bible.md` (and the cast table if there is a new character; add new characters to `CAST` in `laughing-box/characters/make_characters.py` and rerun it), add a row to `laughing-box/README.md`, then run `python laughing-box/claude/build_claude_files.py` so the Claude copies, writer skill and claude.ai ZIP pick it up. `python .agents/check_skill.py` must pass.

## Hard rules

- 100 % original. Never upload, trace or copy other creators' videos. The reference videos in `reference-analysis/` are for studying technique only.
- Family-friendly comedy: no violence beyond cartoon slapstick, no insults about age, body, nationality or religion. The joke is the situation, never the person.
- Keep characters on-model: same colours, outfits, voices and names as the bible.
- Brand: channel **Laughing Box**, handle **@Officiallaughingbox** on all platforms. Brand kit in `laughing-box/brand-kit/`.
