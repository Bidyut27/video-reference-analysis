# Laughing Box rules

This workspace makes **Laughing Box**, an original cartoon comedy channel (@Officiallaughingbox) for a worldwide, all-ages audience.

- For any episode, topic, cover, posting-copy or re-render task, use the `laughing-box-episode` skill (`.agents/skills/laughing-box-episode/SKILL.md`). For writing only (no rendering), use `laughing-box-writer`.
- 100 % original: every picture, voice and sound is generated by code in this repo. Never download, trace or re-upload other creators' videos. `laughing-box/reference-analysis/` is for studying technique only.
- Keep Grandpa, Grandma, Leo, Mittens, Biscuit and Cookie on-model (see `.agents/skills/laughing-box-episode/references/series-bible.md`). Reuse the character code from earlier episodes; never redraw a character.
- Every episode ships a 2160×3840 (4K, 9:16) video at −14 LUFS with peak ≤ −1 dBFS, a 1080×1920 9:16 cover, and YouTube/Facebook/Instagram posting copy in the episode README.
- Episodes live in `laughing-box/episodes/NN-<slug>/`. After finishing one, add it to the series-bible episode log and `laughing-box/README.md`.
- Family-friendly slapstick only. The joke is the situation, never a person's age, body, nationality or religion. Never use "kids", "children" or "nursery" in titles, tags or keywords.
- Don't commit `__pycache__`, temporary renders or the Kokoro model files.
