# Grandpa vs. the Self-Checkout (original short)

An original 62.5 s wordless cartoon in 9:16, built from the sample story in [`production/templates.md`](../../production/templates.md#4-sample-original-story-75-s-style-c) and the rules in the [production blueprint](../../production/blueprint.md).

- **Video:** [`grandpa-vs-self-checkout.mp4`](grandpa-vs-self-checkout.mp4), 1080×1920, 24 fps, H.264 + AAC 48 kHz, −14 LUFS
- **Contact sheet (1 frame/s):** [`contact-sheet.jpg`](contact-sheet.jpg)

All characters, the "Pickle Mart" store, the art and the sound are generated by the scripts in this folder. No third-party artwork, samples, music or fonts beyond the system DejaVu fonts are used.

## Story beats

| Time | Beat | Techniques borrowed from the references |

| 39.3–47.0 s | **Twist 1:** silence drop, ✔, golden victory | Silence on the gag (Ref 1), colour grade as emotion (Ref 2) |
| 47.0–56.0 s | **Twist 2:** he paid for the next shopper's giant cart | Second reversal in the final act (Ref 3); record scratch; navy "gloom" grade |
| 56.0–62.5 s | **Button/loop:** grandma pays in one tap; final ✖ glow mirrors the hook | Held reaction ending that loops back to the opening (Refs 2–3) |

## Rebuild

```bash
sudo apt-get install -y libcairo2-dev pkg-config python3-dev ffmpeg
pip install pycairo numpy scipy
python make_video.py --stills stills/          # optional: one PNG per shot for review
python make_video.py picture.mp4               # ~1 min on 4 cores
python make_audio.py soundtrack.wav
ffmpeg -i picture.mp4 -i soundtrack.wav -filter:a "loudnorm=I=-14:TP=-1.5:LRA=11" \
  -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest -movflags +faststart grandpa-vs-self-checkout.mp4
```

Edit the shots or SFX cue times in `timeline.py`. Both renderers read it, so picture and sound stay in sync.

## Limits

This is procedural vector animation: pose-to-pose motion, camera moves and overlays, without hand-drawn in-betweens or AI image-to-video. It shows the structure, timing and sound design of the blueprint. For the painterly look of the references, use the AI or 2D toolchains in [`production/tools-and-workflow.md`](../../production/tools-and-workflow.md) on the same shot list.
