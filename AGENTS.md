# AGENTS.md

Instructions for AI coding agents (Codex, Cursor, Gemini CLI, GitHub Copilot, Claude Code and others) working in this repository.

This repo produces **Laughing Box**, an original cartoon comedy channel. Videos, covers and brand art are generated procedurally with Python (Cairo for the picture, Kokoro TTS for the voices, numpy/scipy for the sound).

- **New episode, topic ideas, cover, posting copy, re-render:** follow the skill at [`.agents/skills/laughing-box-episode/SKILL.md`](.agents/skills/laughing-box-episode/SKILL.md).
- **Characters, voices, colours, episode log:** [`.agents/skills/laughing-box-episode/references/series-bible.md`](.agents/skills/laughing-box-episode/references/series-bible.md).
- **Chat AIs without repo access:** [`.agents/skills/laughing-box-episode/references/chat-prompt.md`](.agents/skills/laughing-box-episode/references/chat-prompt.md).
- **Writing only (ideas, script, shot list, posting copy, AI prompts):** [`.agents/skills/laughing-box-writer/SKILL.md`](.agents/skills/laughing-box-writer/SKILL.md) (generated; edit `laughing-box/claude/laughing-box-writer/SKILL.md`).
- **Always-on rules (Antigravity):** [`.agents/rules/laughing-box.md`](.agents/rules/laughing-box.md). **Claude and Antigravity setup:** [`laughing-box/claude/README.md`](laughing-box/claude/README.md).

## Layout

| Path | Contents |
|---|---|
| `laughing-box/episodes/NN-<episode>/` | One numbered folder per episode: scripts, video, cover, README with posting copy |
| `laughing-box/brand-kit/` | Logo, profile picture, banners, watermark and their generator |
| `laughing-box/production/` | Blueprint, templates, QC checklist, tool guide |
| `laughing-box/reference-analysis/` | Analysis of reference videos (technique study only, never re-upload) |

## Rules

- Everything must be original and generated by code in this repo. No third-party art, music or samples.
- Every episode ships a 4K 9:16 video, a 9:16 cover and posting copy (see the skill).
- Don't commit `__pycache__` or temporary renders.
- `.claude/skills/`, `.agents/skills/laughing-box-writer/` and `laughing-box/claude/project-knowledge/` are generated. Edit the sources, then run `python laughing-box/claude/build_claude_files.py`.
